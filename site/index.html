Baromètre des prises étrangères sur la France

Si le robinet se ferme demain, combien de jours la France tient-elle ?

Pour le pétrole, la loi impose 90 jours de stocks stratégiques. Pour les médicaments essentiels, deux mois. Pour les terres rares, les puces, les engrais ou le cloud de l'État : aucun seuil.

Le baromètre mesure, produit par produit, de qui nous dépendons, sur quoi, pour combien de temps, et avec qui nous pourrions bâtir d'autres alliances.

Le test des 100 jours

Cent produits vitaux. Pour chacun, un seul chiffre : le nombre de jours que le pays tient si le flux extérieur s'arrête. Sous le seuil fixé par la loi, l'État doit présenter un plan de reconstitution. Cliquez un produit pour ouvrir sa fiche et voir avec qui bâtir des alliances.

Qui tient le robinet ?

La prédation n'est plus militaire. Elle passe par la matière, le code, le droit, le capital, les récits et les relais. Chaque case indique si le levier a déjà été actionné contre la France ou l'Europe.
